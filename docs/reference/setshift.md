# Set-shifting data

Higgins et al. (2009) re-analyzed data (Roberts et al., 2007) that
included 14 studies evaluating the set-shifting ability in people with
eating disorders by using a prediction interval. Standardized mean
differences in the time taken to complete Trail Making Test between
subjects with eating disorders and healthy controls were collected.
Positive estimates indicate impairment in set shifting ability in people
with eating disorders.

## Usage

``` r
data(setshift)
```

## Format

A data frame with 14 rows and 2 variables

## Details

- `y`: Standardized mean difference

- `sigmak`: Standard error
