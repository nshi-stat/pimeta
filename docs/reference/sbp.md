# Systolic blood pressure (SBP) data

Riley et al. (2011) analyzed a hypothetical meta-analysis. They
generated a data set of 10 studies examining the same antihypertensive
drug. Negative estimates suggested reduced blood pressure in the
treatment group.

## Usage

``` r
data(sbp)
```

## Format

A data frame with 10 rows and 2 variables

## Details

- `y`: Standardized mean difference

- `sigmak`: Standard error

- `label`: Labels for each generated study

## References

Riley, R. D., Higgins, J. P. T, and Deeks, J. J. (2011). Interpretation
of random effects meta-analyses. *BMJ.* **342**: d549.
[doi:10.1136/bmj.d549](https://doi.org/10.1136/bmj.d549)
